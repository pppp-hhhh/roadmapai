# v1.1 设计稿 · 方向 4：AI 闭环

> 范围：把 v1.0 已有的"AI 输出"（路线 / 任务 / 闪卡 / 导师回答）打通成可互相沉淀的回路。
> 关联总览：[roadmapai-v1.1-design-overview.md](./roadmapai-v1.1-design-overview.md)
> 状态：v1.1 主攻方向之一。

---

## 一、设计目标

1. **让"提问"沉淀为"资产"**：用户在 AI 导师问过的好问题，应该能一键变成闪卡、任务、资源收藏。
2. **让"任务"反哺"AI 上下文"**：在任务详情页能直接基于当前任务提问，不必切换页面。
3. **让"记不住"自动触发"重解释"**：闪卡复习失败时，自动调用 AI 用另一种方式解释。
4. **保持用户掌控感**：所有沉淀动作都是显式操作 + 二次确认，不在后台偷偷入库。

---

## 二、回路设计

四条核心回路：

```
   ┌──────────────────────────────────────────────────────┐
   │                                                      │
   │  ① AI 导师回答 ─→ 转闪卡  ─→ 进入 /flashcards        │
   │  ② AI 导师回答 ─→ 转任务  ─→ 进入 /roadmap/:id       │
   │  ③ 任务详情   ─→ 向 AI 提问 ─→ 回到导师              │
   │  ④ 闪卡复习失败 ─→ AI 重新解释 ─→ 形成新闪卡          │
   │                                                      │
   └──────────────────────────────────────────────────────┘
```

---

## 三、回路 ①：AI 回答 → 闪卡

### 3.1 触发位置

AI 导师页（`/tutor`）的每条助手消息底部操作栏。

### 3.2 操作栏设计

```
┌──────────────────────────────────────────────────┐
│ 🤖 AI 导师                            14:32      │
│                                                  │
│  损失函数衡量模型预测值与真实值之间的差距...     │
│  ```                                            │
│  Loss = (y_pred - y_true)^2                      │
│  ```                                            │
│                                                  │
│ ───────────────────────────────────────────────  │
│  [📋 复制]  [🧠 转闪卡]  [✅ 转任务]  [👍] [👎]  │
└──────────────────────────────────────────────────┘
```

- 操作栏仅在消息完整接收后出现（`isStreaming === false`）。
- 鼠标悬浮消息时显示，整条消息底部淡入。

### 3.3 转闪卡流程

点击"🧠 转闪卡" → 弹出右侧抽屉，宽度 480 px：

```
┌──────────────────────────────────────┐
│ 转为闪卡                       [×]  │
│ ────────────────────────────────   │
│ 选择路线                           │
│ [机器学习入门           ▾]         │
│                                      │
│ 问题                                │
│ ┌────────────────────────────────┐  │
│ │ 什么是损失函数？                │  │
│ │ (从回答自动提取)                │  │
│ └────────────────────────────────┘  │
│                                      │
│ 答案                                │
│ ┌────────────────────────────────┐  │
│ │ 损失函数衡量模型预测值与真实值  │  │
│ │ 之间的差距...                   │  │
│ │ (可编辑)                       │  │
│ └────────────────────────────────┘  │
│                                      │
│ ☑ 加入今日学习队列                  │
│                                      │
│           [取消]  [保存]             │
└──────────────────────────────────────┘
```

- **问题自动提取**：从回答中识别"X 是什么"等定义类表述，提取为问题。如果提取失败，让用户手动填。
- **答案自动填入**回答全文，用户可编辑。
- **路线绑定**：必选，从下拉中选择目标路线。
- **加入今日学习队列**：勾选后立即出现在 `/flashcards` 的"待学习"列表。

## 五、回路 ③：任务详情 → AI 提问

### 5.1 触发位置

路线详情页（`/roadmap/:id`）的每个任务卡片底部。

### 5.2 操作行

```
┌────────────────────────────────────────┐
│ ✓ 3. 练习：手写梯度下降代码           │
│   💻 练习  · 45 分钟                   │
│                                        │
│ ────────────────────────────────────  │
│  [🤖 基于此任务提问]  [📌 收藏]  [⤴]  │
└────────────────────────────────────────┘
```

- **基于此任务提问**：点击 → 弹出 AI 导师抽屉（不离开当前页），预填上下文：
  > "（背景：我正在学习「机器学习入门」第 3 关「监督学习」，当前任务「练习：手写梯度下降代码」，请围绕此上下文回答）我的问题是：___"
  用户在抽屉输入问题后点击发送，跳转到 `/tutor` 并自动 send。
- **收藏**：v1.1 新增的收藏功能入口，详见 5.3。
- **⤴**：折叠任务。

### 5.3 抽屉式 AI 提问（v1.1 新增）

```
┌──────────────────────────────────────────────────┐
│ AI 导师 · 基于当前任务                      [×]  │
│ ────────────────────────────────────────────   │
│ 上下文（自动填入）                              │
│ ┌────────────────────────────────────────────┐  │
│ │ 📖 机器学习入门 → 第 3 关 → 任务「手写     │  │
│ │ 梯度下降代码」                              │  │
│ └────────────────────────────────────────────┘  │
│                                                  │
│ 你的问题                                        │
│ ┌────────────────────────────────────────────┐  │
│ │ 梯度下降的学习率如何选择？                  │  │
│ └────────────────────────────────────────────┘  │
│                                                  │
│ 快捷提示                                        │
│ [用图解释] [给个例子] [对比其他方法]            │
│                                                  │
│              [取消]  [在 AI 导师页打开 →]        │
└──────────────────────────────────────────────────┘
```

- 抽屉宽 560 px，从右滑入。
- 点击"在 AI 导师页打开 →"会跳转到 `/tutor` 并自动填好问题+上下文。

## 六、回路 ④：闪卡复习失败 → AI 重解释

### 6.1 触发位置

闪卡复习页（`/flashcards`）复习时，质量评分 0-2（重来/吃力/较难）后。

### 6.2 行为

```
                  ┌────────────────────────────┐
                  │ 你的回答：吃力 😓          │
                  │ 正确答案是：损失函数...     │
                  │                            │
                  │  ✨ AI 重新解释这个问题？  │
                  │                            │
                  │ [不需要]  [让 AI 解释 →]   │
                  └────────────────────────────┘
```

- 点击"让 AI 解释 →" → 调用 AI 导师接口，请求"用另一种方式解释这个问题"。
- 回答显示在浮层中（不离开闪卡复习流程）。
- 解释回答底部有"📇 把这段解释转成新闪卡"，进入回路 ①。

### 6.3 时机选择

只在评分 0-2 时弹出（"重来/吃力/较难"），评分 3-5（良好/简单/完美）时不弹，避免打断学习节奏。

## 七、收藏功能（v1.1 新增基础设施）

收藏是 AI 闭环的辅助设施，让用户能跨页面收集"以后想回看"的内容。

### 7.1 可收藏对象

- 任务（来自路线详情页）。
- 资源（来自任务详情）。
- AI 回答（来自导师页）。
- 闪卡（来自闪卡页，可收藏作为重点复习）。

### 7.2 入口

- 路线详情页操作行（回路 ③）。
- 资源卡片右上角悬浮按钮。
- AI 回答操作栏的"📌 收藏"。
- 闪卡详情弹窗右上角。

### 7.3 收藏页

新增 `/favorites` 路由，UI：

```
┌──────────────────────────────────────────┐
│ 收藏夹                          [+ 新建] │
│ ─────────────────────────────────────── │
│                                          │
│  [全部] [任务] [资源] [AI 回答] [闪卡]  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ 📖 任务 · 机器学习入门             │  │
│  │ "深入理解损失函数"                 │  │
│  │ 收藏于 2 天前  ·  [打开] [取消收藏]│  │
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │ 🔗 资源 · 机器学习入门             │  │
│  │ "梯度下降可视化（3Blue1Brown）"    │  │
│  │ 收藏于 5 天前  ·  [打开] [取消收藏]│  │
│  └────────────────────────────────────┘  │
│                                          │
└──────────────────────────────────────────┘
```

- 顶部 Tab 切换 4 种类型。
- 每条收藏显示所属路线、收藏时间。
- 点击"打开"跳转到原始位置（任务/资源/AI 回答/闪卡）。

## 十、与 v1.0 的差异

| v1.0 元素 | v1.1 改动 |
| --- | --- |
| AI 回答无操作栏 | 增加操作栏（复制/转闪卡/转任务/反馈） |
| 任务卡片无快捷提问 | 增加"基于此任务提问" |
| 闪卡复习失败无 AI 介入 | 评分 0-2 时自动询问是否让 AI 重解释 |
| 无收藏功能 | 新增 /favorites 页面 + 4 类收藏 |
| 闪卡只能手动创建 | 支持"AI 回答 → 闪卡" |
| 任务只能由 AI 在生成路线时创建 | 支持"AI 回答 → 任务" |

## 十一、技术实现要点

1. **后端命令**（Rust 端新增）：
   - `add_favorite(type, ref_id, roadmap_id, title, preview)`
   - `remove_favorite(id)`
   - `list_favorites(filter_type?, roadmap_id?)`
   - `extract_qa_from_message(message_id)`：从 AI 回答中智能提取问答对（用于转闪卡）
2. **前端 store**：
   - 新增 `useFavoriteStore`（增删查）。
   - 复用 `useChatStore` / `useRoadmapStore` / `useFlashcardStore`，不破坏既有接口。
3. **抽屉组件**：
   - 抽取统一的 `<SideDrawer>` 组件，支持右侧滑入、ESC 关闭、背景遮罩。
   - 复用 v1.0 的过渡动效（200ms ease-out）。
4. **AI 二次精炼**：
   - 转任务时调用 `refine_task_content(raw_answer)`，后端把口语化回答转为结构化 markdown。
   - 这是 v1.1 后端的最小增强，前端不感知。

---

## 十二、验收标准

1. AI 回答操作栏在消息流式接收完成 200ms 后淡入。
2. 转闪卡抽屉能在 100ms 内滑入。
3. 任务详情页"基于此任务提问"预填的上下文在跳转 `/tutor` 后正确显示。
4. 闪卡复习评分 0-2 后 300ms 弹出"让 AI 解释"提示。
5. 收藏页 Tab 切换响应 < 100ms。
6. 收藏的"打开"按钮能精确跳到原始位置（保留 query 参数）。

## 一、整体概览

### 1.1 v1.1 目标

在不破坏 v1.0 数据/API 的前提下，给 RoadmapAI 带来 5 项关键升级：

1. **侧边栏重做**（上下文 + 主动提示）— 提升日活与次回访
2. **创建页向导化** — 拉高首条路线完成率与质量
3. **AI 闭环**（4 条回路 + 收藏夹）— 提升长期价值
4. **四态组件体系** — 让产品在不同数据状态下保持一致品质
5. **首次启动引导** — 解决新用户首日激活

### 1.2 关键约束

- 桌面端独占（Tauri），零后端服务
- v1.0 数据/路由/API 100% 兼容
- 5 个方向**大部分独立**，可并行开发
- 1 个全栈工程师（React + Rust）的工作量约 **17 天 ≈ 3.5 周**

## 六、关键路径分析

### 6.1 串行的关键路径

```
S-1 → S-2 → O-1 → O-2
        0.5   1.5    2     0.5   =  4.5 天（最短关键路径）
```

但实际路径会更长，因为还有：

- W-1 → W-2 → W-3（2 天）
- A-1 → A-2 → A-3（4 天）
- ST-1（1 天，作为 ST-2/3/4/5 的前置）

### 6.2 关键路径

```
W-1 → W-2 → W-3 → O-1 → O-2
0.5    1     0.5    2     0.5   =  4.5 天
```

**O-1 是关键路径上最长的 PR（2 天）**，因为它涉及 6 个步骤组件 + GeoIP。

### 6.3 优化建议

- O-1 拆为 O-1a（store + 步骤 0-2）和 O-1b（步骤 3-4 + 完成页）可降低关键路径
- A-1 拆为 A-1a（后端）和 A-1b（前端收藏页）可让前端先并行
- ST-1 是低风险独立 PR，可让最 junior 的人做

## 七、风险与缓解

### 7.1 技术风险

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| OnboardingGate 阻塞 v1.0 升级用户 | 🔴 高 | O-2 加"检测到有路线时自动 markCompleted" |
| AI 闭环依赖后端，PR A-1 卡住则全部 AI 闭环延后 | 🟡 中 | 后端工程师与前端**同时**启动 A-1，提前 1 天对齐 API |
| 侧边栏重写破坏 StudyTimer / 浮窗 | 🟡 中 | S-2 重点回归 v1.0 浮窗，列入冒烟清单 |
| `toRoadmapRequest` 拼接的 goal/difficulty 与 v1.0 不同 | 🟡 中 | W-3 跑 5 条路线对比验证 |
| 4 态组件视觉与 v1.0 内联状态差异 | 🟢 低 | 截图对比 + 设计师 review |

### 7.2 流程风险

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 22 个 PR 太多，review 跟不上 | 🟡 中 | 用 [PR 模板](./roadmapai-v1.1-pr-templates.md) 加快 review；小型 PR 一次合并 2-3 个 |
| 并行分支冲突（多人改 Layout） | 🟡 中 | 各 PR 严格控制 diff 范围；Layout 集中在 S-2 改一次 |
| 灰度期间发现 P0 | 🟢 低 | 准备 hotfix 流程，OnboardingGate 可在设置关闭 |

### 7.3 业务风险

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 引导反而让老用户反感 | 🟢 低 | 引导加 [跳过] 按钮 + 设置可重置 |
| AI 闭环沉淀的低质量闪卡/任务污染数据 | 🟡 中 | 转闪卡抽屉加"勾选加入今日队列"（v1.1 已设计） |
| 侧边栏太重（条目太多） | 🟢 低 | v1.1 控制在 6 个导航项，v1.2 再加 |

## 十一、给团队 / 老板的 1 页摘要

> **v1.1 RoadmapAI 升级排期**
>
> **目标**：让"今天该学什么"从被动查找变为主动推送；让"AI 提问"沉淀为"个人资产"。

> 4. 加载/空/错误状态统一化
> 5. 首次启动 5 步引导
>

> - W2 结束：核心功能完成（侧边栏 + 向导 + AI 闭环）
> - W3 结束：4 态 + 引导完成
> - W4：集成 + 灰度
>
> **风险**：OnboardingGate 升级兼容（已设计缓解）；AI 闭环依赖后端（已规划并行）
>
> **指标**：首条路线完成率 +15%，首日激活率 +30%，AI 闭环转化率追踪中

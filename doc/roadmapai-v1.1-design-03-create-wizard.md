# v1.1 设计稿 · 方向 3：创建页向导化

> 范围：把 v1.0 的 4 字段单页表单重做为 4 步对话式向导，每步给出示例/反例/AI 预期。
> 关联总览：[roadmapai-v1.1-design-overview.md](./roadmapai-v1.1-design-overview.md)
> 状态：v1.1 主攻方向之一。

---

## 一、设计目标

1. **降低首条路线的认知负担**：把"我要告诉 AI 什么"拆成 4 个有边界的问题，每步只问一件事。
2. **让"目标"必填且可模板化**：v1.0 留空会让 AI 自由发挥，结果不可控；v1.1 改为必填并提供模板。
3. **缓解"AI 黑盒"焦虑**：每步展示"AI 接下来会做什么"的预期，提升用户掌控感。
4. **保留 v1.0 的优秀进度弹窗**：四阶段生成进度（大纲/骨架/内容/完成）延续，但用更克制的视觉。

---

## 二、向导流程

### 2.1 四步概览

| 步骤 | 标题 | 关键问题 | 必填 |
| --- | --- | --- | --- |
| 1 | 你想学什么？ | 主题（含示例与反例） | ✅ |
| 2 | 你现在什么水平？ | 入门 / 进阶 / 高级（带描述） | ✅ |
| 3 | 目标是什么？ | 4 选 1 模板 + 自定义补充 | ✅ |
| 4 | 学习偏好 | 每周时长、难度、是否含项目 | ✅ |

每步底部：[上一步] [继续 →]。最后一步是 [生成学习路线]。

### 2.2 进度指示器

顶部条状指示器（不是 v1.0 的圆点+连接线，而是更轻的水平步骤条）：

```
① 主题 ─── ② 水平 ─── ③ 目标 ─── ④ 偏好
   ●          ◐          ○          ○
   当前       已完成     未开始     未开始
```

- 步骤号圆形 32×32，激活态蓝色填充，未激活灰色描边，完成态绿色勾选。
- 连接线 2px，完成态绿色，未完成灰色。
- 标题字号 12px，激活加粗 + 蓝色。

## 四、关键交互

### 4.1 主题输入的智能校验

- **空值**：禁用"继续"按钮。
- **过短（<2 字）**：显示"请更具体一些"。
- **过宽泛（含"编程""AI""数学"等单字）**：显示提示卡"主题太宽泛可能让 AI 输出浅尝辄止，试试更具体的方向"。
- **合理**：继续按钮变蓝，可点击。
- 主题示例卡点击 → 自动填入输入框（用户可继续编辑）。

### 4.2 水平选择

- 单选卡片，3 个固定选项。
- 选中态：蓝色描边 + 蓝色背景。
- 补充说明非必填，留空时 AI 自动判断。

### 4.3 目标选择

- 4 个模板卡片，单选。
- 模板会自动填入"补充说明"的占位文字（如选"求职面试"会预填"我希望在 X 个月内通过 Y 公司的 Z 岗位面试"）。
- 用户可以完全改写补充说明，模板只是占位。

### 4.4 偏好

- 每周时长：4 选 1。
- 难度：3 选 1（卡片式）。
- 是否含项目：2 选 1。
- 这一步收集的"每周时长"会传给 AI 作为估算总学习周期的依据。

### 4.5 返回与编辑

- "← 上一步"保留所有已填字段。
- 顶部进度条点击可跳到任意已完成的步骤（未完成的步骤不可跳）。
- 表单状态保存在 `useWizardStore`（新增），离开页面需确认（防止误退）。

## 五、生成进度（沿用 v1.0 优化）

v1.0 的四阶段弹窗（大纲/骨架/内容/完成）整体保留，但视觉更克制：

```
┌────────────────────────────────────────────┐
│                                            │
│         🧠 AI 正在为你规划学习路径         │
│                                            │
│         ─── ● ─── ● ─── ◐ ─── ○ ───        │
│         主题  水平  目标  偏好              │
│         ✓    ✓    进行中 ...               │
│                                            │
│         ━━━━━━━━━━━━━░░░░░░  68%           │
│                                            │
│         "目标：求职面试"                    │
│         当前正在生成：3/5 个阶段的内容      │
│                                            │
│         [最小化] · 生成完毕会自动跳转       │
└────────────────────────────────────────────┘
```

- 弹窗背景：`bg-black/60` + `backdrop-blur-sm`（沿用 v1.0）。
- 卡片：`bg-white/95` 圆角 `rounded-3xl` 阴影 `shadow-2xl`。
- 进度条：渐变 + 微光（沿用 v1.0 的 `flow` + `shimmer` 动画）。
- 取消按钮：底部小字，点击返回首页，已生成部分可在首页"草稿"中查看（v1.1 新增）。

## 六、首页草稿区（配套新增）

生成中途取消后，首页顶部出现"草稿"区：

```
┌────────────────────────────────────────────┐
│ 📝 草稿 (1)                                 │
│ ┌────────────────────────────────────────┐ │
│ │ 机器学习入门 · 已完成 3/5 阶段    [续] │ │
│ └────────────────────────────────────────┘ │
└────────────────────────────────────────────┘
```

- 点击 [续] 回到生成弹窗继续（如果还在生成中）或进入详情页（如果已生成完）。
- 草稿在数据库中标记为 `is_draft = true`，不会出现在"我的路线"主列表。

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `bg-gray-50` | `bg-gray-900` |
| 步骤条激活 | `bg-primary-500 text-white` | 同上 |
| 步骤条完成 | `bg-green-500 text-white` | 同上 |
| 步骤条未激活 | `bg-white border border-gray-300` | `bg-gray-800 border border-gray-600` |
| 单选卡片 | `bg-white border border-gray-200` | `bg-gray-800 border border-gray-700` |
| 单选卡片选中 | `bg-primary-50 border-primary-500` | `bg-primary-900/30 border-primary-500` |
| 输入框 | `bg-white border border-gray-200 rounded-xl` | `bg-gray-800 border border-gray-700` |
| 提示卡（好示例） | `bg-blue-50 border border-blue-200` | `bg-blue-900/20 border border-blue-800` |
| 提示卡（坏示例） | `bg-amber-50 border border-amber-200` | `bg-amber-900/20 border border-amber-800` |

| 主按钮 | `bg-primary-600 hover:bg-primary-700 text-white` | 同上 |

## 八、与 v1.0 的差异

| v1.0 元素 | v1.1 改动 |
| --- | --- |
| 单页 4 字段表单 | 拆为 4 步向导 |
| 主题输入无校验 | 智能提示宽泛/不合理 |
| 目标留空 | 改为必填，4 模板 + 自定义 |
| 难度 + 水平 两组按钮 | 水平放第 2 步，难度放第 4 步 |
| 每周时长字段在 settings | 收集到创建流程中 |
| 无草稿机制 | 中途取消后保留草稿 |
| 步骤指示器样式 | 圆点+连线 改为 水平步骤条 |

## 九、技术实现要点

1. **状态**：新增 `useCreateRoadmapWizardStore`，保存 4 个步骤的所有字段。
2. **校验**：每步都有独立的 `validate()` 函数，未通过时禁用"继续"按钮。
3. **API**：v1.0 的 `generateRoadmap(request)` 接口保持不变，只需在客户端拼装 4 步字段后调用。
4. **进度事件**：复用 v1.0 的 `ProgressEvent` 流式订阅，不需改后端。
5. **草稿持久化**：生成调用时即落库（`is_draft = true`），中途取消不删除；完成生成后置为 `is_draft = false`。
6. **可访问性**：每步都有 `<fieldset>` + `<legend>`，单选/多选用 `<input type="radio">` 实现，键盘可达。

---

## 十、验收标准

1. 从首页点击"创建路线"到进入第 1 步 < 100ms。
2. 4 步全部走完（平均用户）应在 90 秒以内（v1.0 平均 60 秒，但质量提升）。
3. 主题输入"AI"时显示警告，"机器学习"时不显示。
4. 取消生成后首页出现草稿卡，点击"续"可继续。
5. 任何一步的"继续"按钮在未通过校验时禁用。
6. 返回上一步时所有已填字段保留。

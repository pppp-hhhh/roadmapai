# v1.1 设计稿 · 方向 1：侧边栏重做

> 范围：把 v1.0 的 16px 图标条重做为"上下文 + 主动提示 + 主导航 + 全局"的四段式可折叠侧边栏。
> 关联总览：[roadmapai-v1.1-design-overview.md](./roadmapai-v1.1-design-overview.md)
> 状态：v1.1 主攻方向之一

---

## 一、设计目标

1. **让"今天该做什么"从被动查找变为主动推送**：今日待办 = 待复习闪卡数 + 未完成任务数。
2. **承载更多模块而不显拥挤**：从 5 个图标扩到约 10 个功能入口仍可用。
3. **新用户有引导**：通过当前路线缩略 + 状态徽标传递"现在进行到哪一步"。
4. **不破坏 v1.0 的视觉语言**：沿用 `primary` 蓝、圆角、浅/深主题。

---

## 二、信息架构

侧边栏从上到下分四段（自上而下）：

| 段 | 名称 | 内容 |
| --- | --- | --- |
| A | 当前上下文 | 当前路线缩略卡（标题、阶段进度环、当前阶段名） |
| B | 今日待办 | 3 类小卡片：待复习闪卡 / 今日未完成任务 / 路线有更新 |
| C | 主导航 | 6 个一级入口：首页、创建路线、记忆卡片、AI 导师、收藏夹（v1.1 新增）、统计（v1.1 新增） |
| D | 全局 | 设置、主题切换、用户菜单（v1.1 新增）、折叠/展开按钮 |

折叠态宽度：64px（与现状一致，图标 only）。
展开态宽度：288px。
宽度变化通过 CSS transition 平滑过渡，200ms ease-out。

## 四、关键组件

### 4.1 当前路线卡（A 段）

- **有当前路线时**：显示路线标题、单行进度环（沿用 v1.0 的 SVG 圆环）、当前阶段名、整体完成度百分比。点击跳转到 `/roadmap/:id`。
- **无当前路线时**：显示提示卡"还没有开始学习 →" + "创建你的第一条路线"按钮。
- **多路线切换**：右上角小箭头下拉，列出最近 3 条 + "全部路线"入口。
- **视觉**：白底（深色主题对应 `gray-800`），圆角 `rounded-2xl`，悬浮阴影 `hover:shadow-md`，描边 `border border-gray-200`。

### 4.2 今日待办卡（B 段）

- 三类待办各自一行，左侧 emoji 标识 + 简短描述，右侧数量徽标 + 箭头。
- **空状态**：不显示该段，整段隐藏（不显示"今天没有待办"等空卡）。
- **交互**：点击整行跳转到对应页面（`/flashcards` / `/roadmap/:id` / `/tutor`）。
- **徽标颜色**：
  - 橙色（待复习闪卡，对应 `bg-orange-100`）。
  - 蓝色（今日未完成任务，对应 `bg-blue-100`）。
  - 紫色（路线更新/AI 建议，对应 `bg-purple-100`）。
- **数量 > 99 时**：显示 `99+`。

### 4.3 主导航项（C 段）

- 列表项高度 40px，左侧 20px 图标 + 右侧 14px 文字标签。
- **激活态**：`bg-primary-100 dark:bg-primary-900/30` + `text-primary-600` + 左侧 3px 圆角指示条。
- **未激活态**：`text-gray-500`，悬浮时 `bg-gray-100 dark:hover:bg-gray-800`。
- **数字徽标**（用于记忆卡片）：红色圆点 `bg-red-500`，文字 10px，定位右上。

| 入口 | 图标 | 路由 | 备注 |
| --- | --- | --- | --- |
| 首页 | `Home` | `/` | 路线列表 |
| 创建路线 | `PlusCircle` | `/create` | 复用 v1.0 |
| 记忆卡片 | `Brain` | `/flashcards` | 显示待复习数 |
| AI 导师 | `Bot` | `/tutor` | v1.0 的 `Layers` 改为更直观的 `Bot` |
| 收藏夹 | `Star` | `/favorites` | **v1.1 新增**，收藏任务/资源/AI 回答 |

### 4.4 全局段（D 段）

- 沿用 v1.0 的主题切换按钮（Sun/Moon）。
- 用户菜单：v1.1 新增，下拉显示：账号、本地数据导出、版本号、退出登录（占位，云同步上线后启用）。
- 折叠/展开按钮始终在最底部。
- 折叠时整段收为图标，文字标签隐藏。

## 六、交互细节

1. **折叠/展开**
   - 默认展开（首次启动），记住用户偏好（`localStorage` / store）。
   - 快捷键：`Ctrl/Cmd + B` 切换。
   - 折叠动画：宽度 200ms 过渡，所有文字/卡片 fade-in/out 150ms。
2. **当前路线切换**
   - 顶栏下拉显示最近 3 条路线 + 搜索框 + "查看全部"。
   - 切换不刷新页面，仅更新 store 中的 `currentRoadmapId`。
3. **数字徽标**
   - 实时刷新：进入 `/flashcards` 复习后回到任意页，徽标数量立即减少。
   - 刷新机制：每 30 秒轮询一次 store（v1.0 的 `useEffect` 模式）。
4. **当前路线卡 hover**
   - 显示"快速操作"浮层：标记完成、暂停路线、归档。
   - 暂停后：A 段改为灰底 + "已暂停"徽标，进度环定格。

## 七、视觉规范

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 侧边栏背景 | `bg-white` | `bg-gray-900` |
| 段分割 | `border-b border-gray-100` | `border-b border-gray-800` |
| 段标题 | `text-xs font-medium text-gray-400 uppercase tracking-wider` | 同上 |
| 主导航激活 | `bg-primary-50 text-primary-700` | `bg-primary-900/30 text-primary-400` |
| 数字徽标 | `bg-red-500 text-white` | 同上 |
| 当前路线卡 | `bg-white border border-gray-200` | `bg-gray-800 border border-gray-700` |
| 待办卡 | `bg-white border border-gray-200` | `bg-gray-800 border border-gray-700` |
| 折叠按钮 | `text-gray-400 hover:text-gray-600` | `text-gray-500 hover:text-gray-300` |

字体：沿用 Inter，字号 14px（导航文字）、12px（待办描述）、10px（数字徽标）。
圆角：卡片 `rounded-2xl`，徽标 `rounded-full`。
阴影：仅悬浮态 `hover:shadow-md`，默认无阴影（保持侧边栏轻盈）。

## 八、技术实现要点

1. **状态**：
   - 新增 `useSidebarStore`：`isCollapsed` / `currentRoadmapId` / `todayTodo`。
   - 复用 `useRoadmapStore.fetchRoadmaps` + `useFlashcardStore.fetchDueCards` 计算今日待办。
2. **响应式**：
   - 桌面端（≥1024px）：固定 64/288px 宽。
   - 平板（768-1023px）：默认折叠，点击展开为浮层。
   - 桌面端不存在 <768px 场景（Tauri 应用最小窗口由系统决定，建议最小 1024×700）。
3. **键盘可达性**：
   - 折叠态：图标按钮需 `title` 提示，Tab 顺序保持：上下文卡 → 主导航 → 全局。
   - 展开态：所有文字链接可 Tab 聚焦，焦点环沿用 `focus:ring-2 focus:ring-primary-500`。
4. **性能**：
   - 当前路线卡与待办卡使用 `React.memo`，避免全局刷新时重渲。
   - 数字徽标数字变化时使用 `transition-all duration-300` 平滑过渡。

## 九、对 v1.0 的兼容与迁移

- 路由表保持兼容：`/` `/create` `/roadmap/:id` `/flashcards` `/tutor` `/settings`。
- 新增路由 `/favorites` `/stats`：在 `App.tsx` 中以 `<Route>` 形式挂载，v1.1 首次发布时两个新页面可用最简版（占位 + 引导），不阻塞主流程。
- `useSidebarStore` 单独存在，不修改现有 4 个 store 的接口。

---

## 十、验收标准

1. 折叠/展开在 60Hz 屏幕无掉帧。
2. 待办数字在 5 秒内反映真实数据（进入 `/flashcards` 复习后徽标减少）。
3. 快捷键 `Ctrl/Cmd + B` 可切换。
4. 新用户首次启动看到 A 段"创建第一条路线"提示卡，点击直接进入 `/create`。
5. 当前路线切换不会触发页面刷新，URL 保持不变。
6. 视觉对比 v1.0 仅在侧边栏区域，主体内容区布局 0 改动。

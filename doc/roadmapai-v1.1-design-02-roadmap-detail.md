# v1.1 设计稿 · 方向 2：路线详情页主+侧布局

> 范围：放弃 v1.0 的"时间线 + 大弹窗嵌套"模式，改为左侧时间线 + 右侧主内容面板 + 资源侧拉抽屉。
> 关联总览：[roadmapai-v1.1-design-overview.md](./roadmapai-v1.1-design-overview.md)
> 状态：v1.1 候选（次优先），可在 1.1.x 后续迭代或 1.2 落地。

---

## 一、设计目标

1. **消除弹窗嵌套**：v1.0 的"点阶段 → 弹窗 → 展开任务 → 弹窗编辑资源"是 3 层弹窗嵌套，操作断裂且视野受限。
2. **始终保留全局视野**：左侧时间线常驻，可一眼看到整条路线的进度。
3. **资源编辑不影响主体**：改用侧拉抽屉 + 实时预览，编辑时主内容可见。
4. **支持键盘流与命令面板**：重度用户可纯键盘操作（任务勾选、阶段切换、跳转）。

---

## 二、布局架构

整体改为三栏布局（自左向右）：

| 栏 | 名称 | 宽度 | 内容 |
| --- | --- | --- | --- |
| 1 | 全局侧边栏 | 64 / 288 px | 方向 1 已重做 |
| 2 | 路线时间线 | 320 px | 阶段列表，可折叠为图标列 |
| 3 | 主内容 | flex-1 | 阶段详情（目标、任务、资源） |

特殊元素：
- **顶部头条**：路线标题、整体进度环、操作菜单（重命名、归档、导出）。
- **右侧资源抽屉**：从右滑入，宽 480 px，可关闭。

## 三、关键组件

### 3.1 路线头条（顶部）

- 左：返回按钮 + 路线标题（大字号 24px，可点击重命名）。
- 中：副标题（阶段数、总任务、已完成、总时长），字号 12px，灰色。
- 右：操作菜单（`MoreHorizontal`），下拉包含：编辑路线信息、归档、导出、删除。
- 进度环：120×120，沿用 v1.0 风格，固定在头条右侧。
- 高度：80 px，白底 + 底部分割线。

### 3.2 时间线栏（左侧 320 px）

- 标题："路线进度" + 总进度百分比。
- 列表项：
  - 圆形图标：序号 / 锁定 / 测验 / 警告（fallback）。
  - 名称 + 类型徽标（学习 / 测验 / 项目）。
  - 进度条（如果该阶段有任务）。
  - 时长。
  - 激活项：`bg-primary-50` + 左侧 3 px 蓝条。
- 列表底部："+ 添加自定义阶段"（v1.1 新增，默认隐藏，可在设置中开启）。
- 折叠态：变为 56 px 宽的图标列，hover 显示 tooltip。
- **吸附**：滚动时栏头吸顶。

### 3.3 主内容区（flex-1）

- **阶段目标卡**：纯展示，居中宽度 `max-w-3xl`。
- **任务列表**：
  - 每项左侧 checkbox（可点击切换完成）。
  - 类型图标（沿用 v1.0 五色编码）。
  - 标题、时长、展开/收起箭头。
  - 展开后展示：markdown 内容、代码块、练习、资源行。
- **资源行**：
  - 横滑卡片（沿用 v1.0 风格），右侧"+ 添加资源"虚框。
  - 卡片点击 → 右侧抽屉编辑（v1.0 是悬停按钮，v1.1 改为点击更易触达）。
- **下一步提示卡**：当阶段任务全部完成时，显示蓝色卡片引导"开始测验 / 进入下一关"。

### 3.4 资源抽屉

- 宽度 480 px，从右滑入，背景遮罩 `bg-black/30`。
- 字段：标题、URL、类型下拉、摘要、预览按钮。
- 底部：[取消] [保存并继续添加] [保存]。
- 校验：URL 必须以 `http://` 或 `https://` 开头；标题不能为空。

## 四、状态机

### 4.1 阶段状态可视化

| 状态 | 时间线图标 | 颜色 | 主内容显示 |
| --- | --- | --- | --- |
| `locked` | `Lock` | 灰 | 提示卡"完成上一关解锁" |
| `in_progress` | 序号 | 蓝 | 正常显示任务列表 |
| `completed` | 勾选 | 绿 | 任务列表收起，顶部显示"已通过测验 / 完成" |
| `quiz_failed` | `AlertTriangle` | 红 | 顶部显示重试/查看错题按钮 |
| `fallback` | `AlertTriangle` | 黄 | 顶部显示"AI 未生成"提示 + 重新生成按钮 |

### 4.2 任务展开策略

- 默认全部收起（避免长滚动）。
- v1.0 的"所有任务都展开"在长路线时体验差。
- v1.1 改为：当前阶段下"最近一次操作的任务"自动展开，其他收起。
- 任务全部完成时：自动收起所有任务，展示庆祝条。

## 五、键盘交互

| 快捷键 | 行为 |
| --- | --- |
| `↑` / `↓` | 在任务间移动焦点 |
| `Space` | 切换当前任务完成态 |
| `Enter` | 展开/收起当前任务 |
| `n` | 跳到下一关（需解锁） |
| `p` | 跳到上一关 |
| `Ctrl/Cmd + k` | 打开命令面板（跳转任意阶段、搜索任务） |
| `Esc` | 关闭资源抽屉 |

命令面板是一个浮层（沿用 v1.0 路线生成弹窗的视觉语言），含搜索框 + 阶段/任务列表。

## 八、技术实现要点

1. **路由**：`/roadmap/:id` 保持不变，但内部增加 query 参数 `?stage=:order` 用于深链。
2. **状态**：
   - 复用 `useRoadmapStore`（fetchRoadmap / markTaskCompleted / submitQuiz / addResource / updateResource / deleteResource）。
   - 新增本地 UI 状态：`expandedTaskIds: Set<string>` / `selectedStageOrder: number` / `isResourceDrawerOpen: boolean`。
3. **虚拟化**：当某阶段任务 > 50 时，列表虚拟滚动（`@tanstack/react-virtual`）。
4. **资源预览**：URL 预览只展示"已通过格式校验"和元数据（title/description），不做 iframe 嵌入避免 XSS 与跨域问题。
5. **键盘监听**：使用 `useHotkeys` 或自建 hook，监听 `keydown`，避免在 input/textarea 中误触发。

## 九、验收标准

1. 阶段切换响应 < 100ms（点击/键盘均同）。
2. 资源抽屉滑入/滑出动画 200ms ease-out。
3. 长路线（10+ 阶段）滚动时时间线栏不卡顿。
4. 弹窗嵌套层级从 3 层降到 0 层（不再有 `fixed inset-0` 的 StageModal）。
5. 命令面板可在 200ms 内打开，搜索结果实时高亮。
6. 资源 URL 校验失败时，输入框红色描边 + 错误提示。
